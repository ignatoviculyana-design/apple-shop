APPLE SHOP — ИНСТРУКЦИЯ (БЕСПЛАТНОЕ ПОДКЛЮЧЕНИЕ ИИ)

В этой версии ИИ-функция подключается через Google Gemini API, у которого есть бесплатный уровень для некоторых моделей и регионов. Действуют квоты и ограничения; бесплатный доступ не гарантирован для каждого аккаунта/проекта и может измениться. На бесплатном уровне Google может использовать переданные данные для улучшения продуктов — не отправляйте персональные/платёжные данные покупателей.

КАК ПОДКЛЮЧИТЬ:
1. Откройте https://aistudio.google.com/apikey и создайте Gemini API key.
2. В Netlify откройте проект -> Project configuration -> Environment variables.
3. Добавьте переменную:
   Key: GEMINI_API_KEY
   Value: ваш секретный Gemini API key
4. Сохраните и запустите повторную публикацию сайта (redeploy).
5. Не вставляйте ключ в app.js, HTML или в публичный чат. Он должен храниться только в переменных окружения Netlify.

Netlify имеет бесплатный план с месячным лимитом ресурсов/кредитов; при достижении лимита сайт/функции могут быть приостановлены до следующего периода. Проверяйте Usage & billing в Netlify.

СОДЕРЖИМОЕ:
- Каталог из 90 товаров, 6 категорий (без вкладки Б/У Apple)
- Рубли, поиск, корзина, выбор города
- Личный кабинет: изменение ника и фото профиля (сохранение локально в браузере)
- ИИ-чат через Gemini 2.5 Flash-Lite

ОГРАНИЧЕНИЯ:
- Цены ориентировочные, не обновляются автоматически и не являются проверенной средней ценой маркетплейсов.
- Фото тематические из внешних источников, не гарантированно официальные снимки каждой модели.
- Ник и фото сохраняются на этом устройстве в браузере, не синхронизируются между устройствами.
- Настоящие аккаунты/SMS, серверная база, оформление заказов и онлайн-оплата пока не подключены.
